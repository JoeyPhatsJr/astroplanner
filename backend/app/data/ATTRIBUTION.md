# Data attribution

## targets.json — derived from OpenNGC

`targets.json` is generated by `backend/scripts/build_catalog.py` from
[OpenNGC](https://github.com/mattiaverga/OpenNGC) by Mattia Verga, commit
`be3cd6c5498806a2fbb2f7e0452ef802dbb02be0` (2026-10-18).

OpenNGC is licensed under **CC BY-SA 4.0**
(https://creativecommons.org/licenses/by-sa/4.0/). This derivative file
(a 58-object subset with reformatted coordinates and added display names,
broad categories and an `emission_line_dominant` curator flag) is distributed
under the same license.

Fields copied verbatim from OpenNGC: designation, type, constellation, J2000
RA/Dec, major/minor axis (arcmin), V or B magnitude, Messier cross-reference,
common names, identifiers. Fields added by AstroPlanner: `name`, `category`,
`emission_line_dominant` (used only by the Moon-tolerance heuristic).

To regenerate:

```bash
curl -O https://raw.githubusercontent.com/mattiaverga/OpenNGC/<commit>/database_files/NGC.csv
curl -O https://raw.githubusercontent.com/mattiaverga/OpenNGC/<commit>/database_files/addendum.csv
python scripts/build_catalog.py NGC.csv addendum.csv <commit>
```

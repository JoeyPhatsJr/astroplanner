# Data attribution

## targets.json — derived from OpenNGC

`targets.json` is generated by `backend/scripts/build_catalog.py` from
[OpenNGC](https://github.com/mattiaverga/OpenNGC) by Mattia Verga, commit
`be3cd6c5498806a2fbb2f7e0452ef802dbb02be0` (2026-10-18).

OpenNGC is licensed under **CC BY-SA 4.0**
(https://creativecommons.org/licenses/by-sa/4.0/). This derivative file
(a 58-object subset with reformatted coordinates and added display names,
broad categories and an `emission_line_dominant` curator flag) is distributed
under the same license.

Fields copied verbatim from OpenNGC: designation, type, constellation, J2000
RA/Dec, major/minor axis (arcmin), V or B magnitude, Messier cross-reference,
common names, identifiers. Fields added by AstroPlanner: `name`, `category`,
`emission_line_dominant` (used only by the Moon-tolerance heuristic).

To regenerate:

```bash
curl -O https://raw.githubusercontent.com/mattiaverga/OpenNGC/<commit>/database_files/NGC.csv
curl -O https://raw.githubusercontent.com/mattiaverga/OpenNGC/<commit>/database_files/addendum.csv
python scripts/build_catalog.py NGC.csv addendum.csv <commit>
```

## variables.json — AAVSO VSX

`variables.json` (four curated variable stars: SS Cyg, U Gem, R Leo, T CrB) is generated by
`backend/scripts/build_variables.py` from the AAVSO VSX object API
(`https://vsx.aavso.org/index.php?view=api.object`). Coordinates, variability type, magnitude
range, period, epoch, AUID and OID are copied as VSX reports them. Alert thresholds, missions,
type labels and history windows are AstroPlanner curation.

Catalog data: International Variable Star Index (VSX), operated at AAVSO, Cambridge,
Massachusetts, USA.

VSX terms (https://vsx.aavso.org/index.php?view=about.copyright, read 2026-11-02): permission is
granted to display, copy, distribute and download the materials for personal, non-commercial use
only, provided the materials are not modified and copyright notices are retained; mirroring on
another server requires AAVSO permission. This app is local and single-user; a public deployment
would need AAVSO's permission first. The build script sends one request per star, at least 2 s
apart, with an identifying user agent. To regenerate: `python scripts/build_variables.py`.
